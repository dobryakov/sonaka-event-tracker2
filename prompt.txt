Цель проекта - трекинг событий, которые присылают внешние клиенты.

Проект состоит из докер-контейнеров под управлением docker compose:
* Контейнер с БД PostgreSQL
* Контейнер с приложением на Golang
* Контейнер с клиентами на PHP и bash (curl)

Всё делаем и запускаем в контейнерах, избегаем запуска на хосте. Используем docker compose. Обязательно применяем автотестирование, запускаем автотесты автоматически после завершения каждой задачи.

Атрибуты для трекинга (они же - колонки в БД):
* Имя системы клиента system_name (строка)
* ID трекаемого объекта object_id (строка)
* Имя события event_name (строка)
* Произвольные метаданные metadata (JSON)
* Метка времени event_time

Сервер:
* Сервер должен предоставлять HTTP эндпоинт для приёмки событий от клиентов.

Клиенты:
* Клиенты должны работать с сервером по HTTP API.
* Запуск клиентов — разовый `docker compose run --rm` (контейнер выполняет сценарий и завершается), без постоянно висящих клиентских сервисов.

Тестирование:
* Автотесты должны быть написаны на PHP внутри контейнера с клиентами.
* Автотесты должны отправлять событие в сервер, затем проверять конкретно его наличие в БД путём SQL запроса.

В документации должно быть:
* Описание установки и первого запуска.
* Примеры команд запуска PHP и bash клиентов со случайными данными о событии.
* Примеры запуска автотестов.
